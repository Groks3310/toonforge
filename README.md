# ToonForge

Local cartoon studio. No backend, no paid APIs.

## Run

```
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## What works now

- Dashboard and navigation
- Light / Dark / System theme (top right)
- Cartoon Studio: upload a photo, apply our canvas cartoon filter, compare, download PNG

Other studios are labeled Soon until they are actually built.
